Growth uses each series' first observation in the selected interval. Existing Audience calculation rules are reused unchanged.

That read does not modify KPI loading or calculations, provider integrations, synchronization, database schemas, or historical records. Chart series retain their existing provider-source filters. Hardcoded Love Strings Instagram/YouTube demo arrays were removed from the chart path so an empty workspace cannot inherit them.
